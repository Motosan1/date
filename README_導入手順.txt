Basketball Touch Analyst Ver.12 — オフライン起動修正版

修正：従来のVer.11ではサービスワーカー登録処理がなく、HTMLがオフラインで起動しませんでした。Ver.12で登録処理とキャッシュ更新を追加しました。

1. GitHub Pagesの同じ公開先に、このフォルダーのファイル5点（index.html / sw.js / manifest.webmanifest / icon-192.png / icon-512.png）をすべて上書きアップロード。
2. Wi-Fi接続中にiPadのSafariでGitHub PagesのURLを開き、ページを再読み込み。初回はオンラインで開く必要があります。
3. Safariを閉じず数秒待ち、アプリをもう一度開いてください。必要に応じて既存のホーム画面アイコンは維持し、アイコンからも再起動してください。
4. iPadの機内モードにし、ホーム画面のアイコンから再起動。試合一覧・新規作成・シュート入力・分析が使えるか確認してください。
5. データは自動保存される設計ですが、JSONエクスポートを必ず定期実行してください。ブラウザデータ削除・アプリ削除はしないでください。

注意：ファイルアプリのHTMLプレビューではサービスワーカーを登録できません。必ずHTTPS公開URLからSafariで開いてください。GitHub Pagesへのアップロードでは、ZIPそのものではなくZIP内のファイルを配置してください。
